\# ⚡ ProjectArena



\### From Idea to Prototype. From Prototype to Proof.



ProjectArena is a student-focused project engineering and evaluation platform designed to guide projects through a structured journey: defining the idea, designing the solution, building a prototype, testing it, improving it, and defending it before an AI-powered judge.



\## 🎯 Vision



Make it easier for students to turn ideas into well-structured, testable, and presentation-ready projects.



\## ✨ Planned Platform Workflow



\- \*\*G0 — Define:\*\* Identify the problem, target users, objectives, and expected outcomes.

\- \*\*G1 — Design:\*\* Plan modules, system architecture, technology stack, and user flow.

\- \*\*G2 — Build:\*\* Develop the project and its prototype.

\- \*\*G3 — Test:\*\* Evaluate functionality and identify issues.

\- \*\*G4 — Improve:\*\* Refine the project using feedback and evaluation results.

\- \*\*G5 — Defend:\*\* Prepare to explain and defend project decisions before an AI-powered judge.



\## 🖥️ Current Features



\- Interactive project-cover editor.

\- Live preview of project title, description, and creator name.

\- Customizable visual templates and graphics.

\- Project Idea input.

\- Project Blueprint demonstration.

\- Interactive six-stage workflow.

\- Editable Define and Design workspaces.



Some features currently use demonstration logic. Real AI integration, automated testing, and AI judging are planned enhancements and should not be considered complete.

\## 🚀 Run Locally



\### Prerequisites



Install Node.js and npm.



\### Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/NikhilKashyap09/ProjectArena.git

&#x20;  ```



2\. Enter the frontend directory:



&#x20;  ```bash

&#x20;  cd ProjectArena/Frontend

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



4\. Start the development server:



&#x20;  ```bash

&#x20;  npm run dev

&#x20;  ```



5\. Open http://localhost:3000 in your browser.
